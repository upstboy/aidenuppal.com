## Overview

This entry exists so the projects grid shows more than one card and so the "done" status badge is visible. It also demonstrates a project without a cover image, which falls back to a gradient placeholder.

## How to replace it

1. Copy `src/content/projects/_TEMPLATE.md` into a new folder, e.g. `src/content/projects/my-thing/index.md`.
2. Fill in the frontmatter at the top. The folder name becomes the URL, so `my-thing` lives at `/projects/my-thing/`.
3. Put a `cover.jpg` in the same folder and set `cover: ./cover.jpg`.
4. Delete this folder.
