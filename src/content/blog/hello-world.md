This is the first post on the new site. It is here mostly so the blog page is not empty and so the layout has something to render.

## What this site is for

Two things. A place to document projects properly, with photos and the decisions behind them, instead of leaving everything in scattered notes. And a place to write about whatever else seems worth writing down.

## How posts work

Every post is a markdown file in the site's repository. Headings, lists, links, images and code all work the way you would expect:

```bash
# A code block with a language tag gets highlighted
ssh aiden@aiden2w
```

> Blockquotes work too.

Images can sit next to the post file and be referenced with a relative path.
